**Готово, когда:**

- [x] После сохранения и возвращения preview показывает актуальный файл.
- [x] Значения в Env Veil остаются скрытыми.
- [x] Reveal показывает версию, которая актуальна на момент нажатия.

Источник истины: буфер VS Code, если документ не `dirty`; иначе диск. Правило нужно, чтобы не потерять несохранённые правки пользователя в Text Editor. События файла дебаунсятся на 120 мс, потому что одно сохранение даёт несколько событий.
